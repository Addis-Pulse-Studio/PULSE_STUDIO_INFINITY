# Pulse Studio Infinity director rules

When directing a Pulse Studio Infinity film, follow AGENTS.md in this workspace:
answer each Director Desk turn with JSON only, through
`{{PYTHON_WIN}} {{DESK_WIN}}`, never by editing session files directly. Cite cast
members as @Name, never type <Picture N> / <Video N> / <Audio N> tags, keep each
line short enough for its beat, and never restage an action the turn lists as
forbidden. Judge each beat by what is on screen -- watch the clip when you can --
not by what was planned.
